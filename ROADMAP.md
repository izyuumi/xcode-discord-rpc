# Roadmap

Guiding principle: xcode-discord-rpc stays a small, reliable, zero-UI background daemon.
Improvements below focus on correctness, robustness, and maintainability — not new features.

## 1. Bug fixes (now)

- [ ] **Fix `.rb` extension matching.** `ToFileLanguage` matches the literal string
  `"ruby"`, but the extension extracted from a filename is `rb`, so Ruby files never
  get their logo despite the README claiming support (`src/utils/file_language.rs`).
- [ ] **Remove or wire up `current_file_from_source_editor`.** It is more reliable than
  window-title parsing but currently dead code (`src/utils/osascript.rs`). Either switch
  `get_file_details` to use it (with window-title as fallback) or delete it.
- [ ] **Remove `report.json` from the repository root** (leftover artifact) and add it
  to `.gitignore` if generated by tooling.

## 2. Reliability (next)

- [ ] **Responsive shutdown.** `sleep()` blocks up to `update_interval × multiplier`
  seconds, so Ctrl-C / `brew services stop` can hang for a while. Replace with a
  short-interval sleep loop (or condvar) that checks the `running` flag, so shutdown
  takes ≤1s and the activity is always cleared before exit.
- [ ] **Detect missing Automation permission.** The first osascript call fails with a
  distinct error (-1743) when the user hasn't granted Automation access to Xcode /
  System Events. Surface a clear, actionable log message instead of a generic retry loop.
- [ ] **Validate config values on load.** Reject zero/nonsensical values
  (`update_interval = 0`, negative `idle_threshold`) with a helpful error instead of
  busy-looping or panicking later.

## 3. Testing & CI (next)

- [ ] **Unit tests for the pure logic.** Window-title parsing, project-name parsing
  (`"missing value"`, `"workspace document …"`), extension → `FileLanguage` mapping,
  and sleep-multiplier backoff are all pure functions today or easily made so.
- [ ] **CI workflow for PRs.** Single GitHub Actions job on `macos-latest`:
  `cargo fmt --check`, `cargo clippy -- -D warnings`, `cargo test`, `cargo build`.
  The only existing workflow (`brew.yml`) covers releases, not correctness.

## 4. Polish (later, keep minimal)

- [ ] **Log-level flag.** A `--verbose` flag (or `RUST_LOG` support) so users can get
  debug logs from the release binary when reporting issues, instead of debug logging
  being compile-time only.
- [ ] **A few more Xcode-native file types.** Only ones Xcode actually edits and that
  users have asked for (e.g. `.plist`, `.storyboard`/`.xib`, `.md`). Requires matching
  image assets; keep the list short.
- [ ] **Document required macOS permissions in the README** (Automation prompts for
  Xcode and System Events), since this is the most common "it doesn't work" cause.

## Non-goals

To keep the app simple, the following are explicitly out of scope:

- Menu bar UI, settings GUI, or any visible interface
- Support for editors other than Xcode
- Buttons/party features in the Discord presence
- Analytics or update checks
